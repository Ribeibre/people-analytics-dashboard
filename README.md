# People Analytics Dashboard

## 📌 Objetivo

Este projeto tem como objetivo identificar fatores associados ao turnover de colaboradores utilizando técnicas de análise de dados, SQL e Business Intelligence.

A análise foi desenvolvida com Python, SQLite, SQL e Power BI, transformando dados em insights estratégicos para apoiar decisões relacionadas à retenção de talentos.

---

## 🛠 Tecnologias Utilizadas

- Python
- Pandas
- SQLite
- SQL
- Power BI
- DAX

---

## 📂 Dataset

**IBM HR Analytics Employee Attrition & Performance**

Dataset utilizado para análise de fatores associados ao turnover organizacional.

---

## 📊 Principais Métricas

| Indicador | Valor |
|------------|---------|
| Total de Funcionários | 1.470 |
| Total de Desligamentos | 237 |
| Taxa de Turnover | 16,12% |
| Salário Médio | R$ 6.503 |

---

## 🔍 Principais Insights

### Horas Extras

Funcionários que realizam horas extras apresentam taxa de turnover de 30,5%, quase três vezes superior aos demais colaboradores.

### Satisfação

Colaboradores com baixa satisfação registram turnover de 22,8%, enquanto colaboradores mais satisfeitos apresentam apenas 11,3%.

### Work-Life Balance

Funcionários com menor equilíbrio entre vida pessoal e profissional apresentam a maior taxa de turnover da organização.

### Remuneração

Colaboradores desligados apresentam remuneração média aproximadamente 30% inferior à observada entre funcionários ativos.

## ✅ Conclusão

Os resultados demonstram que fatores como horas extras, satisfação, equilíbrio entre vida pessoal e profissional e remuneração estão associados a diferentes níveis de turnover dentro da organização.

O projeto demonstra a aplicação integrada de Python, SQL e Power BI para transformar dados em informações relevantes para tomada de decisão.
